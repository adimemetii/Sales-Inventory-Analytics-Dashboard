# Project Proposal

**Subject:** Propozim i Temës së Projektit - Adi Memeti (Praktika Python & Data Science)

## Project title

**Analiza dhe parashikimi i të dhënave bankare me të dhënat e hapura të TEB (Data Analysis & Predictive Modelling) me dashboard interaktiv në Streamlit.**

## Field

Data analysis, machine learning, statistics, and visualisation in banking. The project includes data cleaning, exploratory analysis, statistical tests, predictive modelling with a baseline comparison, anomaly screening, segmentation, and an interactive Streamlit dashboard according to the structure supported by the real data.

## Languages and tools

Python, Pandas, NumPy, Scikit-learn, SciPy/statistical testing, Plotly, openpyxl, and Streamlit. Code and source documentation are prepared for the public GitHub repository:

<https://github.com/adimemetii/Sales-Inventory-Analytics-Dashboard>

## Data

The only dataset is the supplied Excel workbook with TEB open data. It contains balance-sheet, income-statement, and financial-indicator sheets. No simulated, internal, or fabricated data is used.

## Expected results

- Reusable cleaning and preprocessing pipeline with a quality report.
- Exploratory analysis and statistical tests with interpretation.
- Held-out ML models evaluated with MAE, RMSE, R², and MAPE and compared with a baseline.
- Anomaly flags and statistical period segments where supported by the workbook.
- Interactive Streamlit dashboard.
- Technical documentation and final report with practical recommendations.
